# ZCode Pet（原生预览版）

独立 C++ Win32 桌宠，直接只读观察已经运行的官方 ZCode，无需修改安装包、源码、配置或启用调试端口，也不启动新 agent。

## 运行

解压便携包，双击 `ZCodePet.exe`。保持 `assets` 文件夹与 EXE 同目录。

- 悬停宠物：展开紧凑会话面板；鼠标可移进面板交互，离开两者 260 ms 后自动收起；勾选右键“固定会话面板”后保持显示。固定选择会随设置保存并在重启后恢复。Esc 或手动收起会取消固定。面板基础宽 312 DIP，默认额外放大到 115%，最多同时显示 3 行，每行基础高度 34 DIP，高度随会话数缩短。仅显示铺满面板的会话行，没有顶部标题、关闭按钮或底部计数，也没有外层 padding、独立卡片背景和卡片间隙；会话间用较明显的灰紫分隔线区分，分隔线两端各保留 10 DIP 行内边距。左侧为会话标题，右侧先显示加大加粗的状态持续时间，再显示低饱和浅色实心、深色文字的胶囊。胶囊贴右锚定，时间长度变化不会推动它；按实际文字宽度分配空间，标题占据全部剩余宽度后才省略。状态灯采用半径 7.5 DIP 的单层实心圆，移除淡色外圈：薄荷绿勾为完成，雾蓝圆底内的旋转弧线为工作中，玫瑰粉叉为错误，杏橙叹号为等待回答，薰衣草紫短横为中断，中性灰点为状态未知，蓝灰空心圈为离线，不闪烁。工作中弧线约 1.2 秒旋转一周，限制在现有圆底内，不增加外圈。运行中的标题有约 2.8 秒一轮的蓝紫扫光：56 DIP 宽的清晰字形亮带，中心提高为明亮的银灰紫色，不叠加字形外的模糊柔光，裁剪在标题区域内，不覆盖时间或状态标签。
- 拖动宠物：移动，已展开的会话面板持续跟随，不会因开始拖动而收起。拖拽定位先限制在显示器工作区内，动画刷新不再同时修正位置，避免触边时来回拉扯闪烁，向屏幕内拖回立即响应；滚轮：只缩放宠物。默认宠物为 128 DIP。右键可分别调节宠物大小和面板缩放，也可恢复默认，偏好保存在 `%LOCALAPPDATA%/ZCodePet/settings.ini`。
- 面板滚轮：浏览最近最多 40 个未归档会话；Esc 收起。不抢焦点。
- 点击会话行或完成/等待提醒正文：用 Windows 原生 UI Automation 在 ZCode 侧栏定位项目及完整标题，打开唯一匹配的已有会话。提醒正文跳转后仍保留，叉号只关闭提醒。后台不导航、不发送消息或创建任务；UIA 在独立线程运行，不阻塞动画。找不到、重名、折叠、被筛选或无法聚焦时显示托盘提示，需先在 ZCode 中展开对应项目并让条目可见。当前 AX 未暴露 session ID，故不能保证所有会话均可跳转；不使用模糊匹配或固定坐标猜选。多窗口重复显示同一会话时也拒绝歧义候选。
- 宠物整个窗口矩形（包括 GIF 透明角落）均可悬停、拖动、滚轮及右键。透明像素保留最低非零 alpha 1/255，避免 Windows 分层窗口逐帧穿透，视觉不添加背景框。
- Session 行和提醒正文都有浅紫色 hover / press 反馈，文字、徽章及布局保持固定。行高亮在内部留出 4 DIP 边距；提醒只在原有圆角内着色。悬停保持浅色，按下色明显加深（行 7.5%→23%、提醒 5.5%→20%），工具栏背景及选中图标颜色也平滑过渡。统一使用 CSS ease-out，悬停约 140 ms 渐入、160 ms 渐出，按下 40 ms、抬起 120 ms；短按反馈从按下起至少保留 85 ms，点击动作仍立即执行，移出则取消保留。中途反向从当前颜色继续。交互过渡接入同一个垂直同步时钟，跟随显示器刷新率，结束后提交归位帧并停止高频刷新，不增加固定 60 Hz 定时器。按下拖出不触发导航，关闭按钮仍独立处理。
- 右键宠物或面板：打开图标主导的横向亚克力工具栏，悬停或键盘聚焦时显示说明。尺寸和文字设置在同一横条切换子页；固定/字体模式有选中态。支持方向键、Tab、Enter/Space，Esc、失焦或点击外部关闭。保留尺寸、恢复默认、素材来源和退出功能。
- 托盘图标也能打开面板或退出。关闭面板不会退出宠物。
- 会话和提醒默认以宠物水平中心为锚点，初始位置为整组浮层留出居中空间；靠近屏幕边缘时仍优先保证可见。会话、提醒和工具栏统一使用按系统 DPI 缩放的 16 DIP 最小屏幕边距。各浮层共用避让算法：会话避开宠物，提醒避开会话和宠物，工具栏避开全部可见窗口，并为提醒的外伸关闭钮预留空间。上下放不下时尝试左右空位，尺寸/行数/工具栏子页变化后重新定位；空间极小时选择交叠最小的位置。

界面使用与宠物粉发、紫色缎带协调的奶白樱粉到淡紫渐变，在系统亚克力上叠加 50–56% 的乳白浅色着色层，保留背景的模糊与明暗变化，同时避免深色壁纸使文字对比不足。会话面板、独立提醒与右键工具栏共用 src/theme.h 的调色板，正文为深灰紫，时间为柔和灰紫，工具栏选中态为淡紫。关闭透明效果或材质失败时使用同色系不透明底。

状态灯、胶囊和独立提醒共享固定的浅色底/深色字配对，不采样桌面：完成 #DCEFE9/#376F63、工作中 #DEE9FA/#4C6594、等待回答 #FAE8D3/#8E5B34、错误 #F6DEE8/#924A64、中断 #E8E0F2/#725A8B、未知 #E7E7E9/#656570、离线 #E2E6EB/#596779。七组颜色的文字对比度均达到 4.5:1。左侧实心圆保持 7.5 DIP 半径，不叠加光圈，圆心改为距左侧 18 DIP，标题起点 34 DIP，增加边缘和符号与文字之间的留白。

状态胶囊使用浅色实心底与深色文字，字形按实际 ink bounds 横纵居中。会话标题和时间也按实际字形范围在整行中垂直居中，覆盖中文字体回退、英文下伸部和省略号，不再依赖固定的顶部偏移。几何生成失败时回退到字体度量居中。

面板采用系统 Desktop Acrylic、圆角及 DirectWrite。针对背景亚克力在非激活时回退成实色的行为，保持浮层 non-client 活跃外观，而不通过激活窗口来换取材质；展示及主题/合成变化后重新应用材质。初始化失败会使用实色底。透明效果关闭、高对比、节能等系统回退仍遵循系统策略。无需 WinUI 3、Windows App SDK、WebView2、Python、Node 或额外 VC 运行库。目标最低系统 Windows 11 26200.8875，x64。窗口使用 Per-Monitor V2 DPI 感知，显示器变化时重新布局并重建对应渲染目标。系统 DPI、宠物大小和面板缩放分别处理，提醒的窗口宽度及徽章只跟随系统 DPI；提醒文字使用与主会话行相同的最终字号，随面板缩放同步，窗口高度随一或两行文字调整。

面板优先创建 Direct2D 硬件渲染目标，硬件不可用时回退软件，并缓存文字排版、测量和状态字形，避免每帧重复创建。宠物 GIF 仍使用 GDI+ 在 CPU 上绘制，但复用位图/DC，保留素材原始帧间隔。本机三类浮层实测均为硬件渲染，120 Hz 垂直同步下 UI 平均帧间隔约 8.33 ms。

## 状态的准确范围

在官方版 3.16.3 本机验证：应用进程检测成功，只读列出 5 个已有会话，无需重启 ZCode。

每两秒查询 `~/.zcode/v2/tasks-index.sqlite`，以 READONLY 方式使用 Windows 自带 winsqlite3，包含 WAL 中的已提交记录。不读取凭据。只有新完成回合需要气泡内容时，额外只读打开 CLI 数据库，按会话及回合 ID 获取最终回复摘录。

当前日期官方日志中的 `cua-pip-session` 回合事件作为活动证据。忽略早于当前 ZCode 主进程启动的事件，按 turnId 排除旧回合结束事件。不按运行时长自动降级状态，长任务会持续工作中直到明确结束；程序退出清除运行态。状态栏明确区分日志观察与上次持久化结果。

行末是当前状态已持续多久：`10s`、`2m`、`3h`、`1d`。有明确日志起点时从状态事件算起，完成后从完成时刻继续增长，不再显示任务总用时。没有真实起点的历史/未知/离线状态，从首次观察算起，并加 `≥` 表示至少持续了这么久。标题刷新不会重置计时，新回合或状态变化才重置。已知会话状态变化时，左侧徽章与右侧状态标签同步上抬最多 2.6 DIP 后回落；标题、时间及行布局保持固定。首次观察、同状态刷新及隐藏期间的变化不触发轻跳。后台状态仍每两秒采样。工作中转圈、标题扫光、状态轻跳及浮层进退场共用高精度时钟，由宠物所在显示器的垂直同步信号驱动；120 Hz 下约每 8.33 ms 一帧，切换显示器后自动跟随。UI 待处理帧最多一条，繁忙时跳过旧帧；静态时停止高频绘制，只每 100 ms 检查年龄文本是否变化。时长始终按实际时间差计算，不靠计时器次数累加，也不承诺主线程阻塞时不会跳过中间数字。

这不是官方公开订阅接口：日志缺失、轮转、升级改变格式，或超过读取的末尾 4 MiB 时，运行态可能不可见。已覆盖 AskUserQuestion 的等待回答：只读读取匹配当前活动回合的运行中工具记录，显示等待回答状态、期待动画和独立橙色提醒气泡；有内容时显示问题短摘录。同一 interactionId 只提示一次，开始观察时已有的有效等待也会提示；回答后气泡作为通知记录保留，直到用户手动关闭。回答后恢复工作的状态年龄从工具结束时算起。其他工具的权限审批、子代理状态仍缺少可靠来源，不能将任意运行中的工具猜成待审批。仅支持当前 Windows 用户的本地默认数据目录；远端会话没有本地证据时只显示历史结果。

动画：空闲用待机，空闲悬停用期待，拖动用拿笔待机，日志观察到工作中固定使用思考（不会使用连续绘制），完成用得意，观察到错误/中断用拿笔待机，随后恢复当前状态。多个会话同时存在时，工作中优先思考。GIF 保持原始帧间隔。

新回合完成后，在宠物旁显示独立亚克力提醒（完成标记 + 会话标题），完成及等待回答提醒均保留到用户手动关闭；悬停气泡时左上角显示深灰紫圆形白叉关闭钮，正文点击不关闭。关闭钮为 24 DIP 区域，圆心对准提醒框左上角，向外悬出一半，屏幕边缘为它预留空间；离开后只隐藏按钮。多条提醒依次排队，手动关掉当前气泡后展示下一条，按 workspace/session/turnId/结束时间去重，历史完成记录不会在首次启动时触发通知。会话开始新回合、等待解除、主程序退出或新提醒到达均不会自动撤掉已产生的提醒；它们保留事件发生时的标题及正文。本应用退出后不保存提醒队列。短任务即使在两个采样之间开始结束也会根据明确的结束事件触发；无结束事件不会猜测成功。会话、提醒和工具栏统一采用 CSS ease-in：cubic-bezier(0.42, 0, 1, 1)，起步慢、随后加速；220 ms 轻移进场、110 ms 退场，按真实经过时间和标准贝塞尔时间轴求值；快速反向从当前进度继续，数据/尺寸刷新保留动画进度，手动拖动时直接跟随。提醒使用原生圆角矩形，与会话面板共用系统 Desktop Acrylic、圆角和投影；移除自定义窗口区域与 AccentPolicy，避免背景和轮廓不一致。初始化失败时回退浅色实心底。文字按主会话行字号同步，上下留白收紧为 8 DIP，左侧徽章距边缘 10 DIP，正文从 36 DIP 起排，右侧留白 12 DIP。横向展示半径 10 DIP 的浅薄荷底深绿勾、加粗会话标题及最多两行最终回复摘录。只查询当前匹配回合、可见且已完成的 assistant_response，只读取 text part，跳过思考/工具/合成内容；缺少符合条件的正文则退回标题加完成提示，不取其他回合的回复代替，不调用模型。摘录只在内存展示。

## 亚克力文字实验

默认 DirectWrite 灰度 AA，直接绘制在透明亚克力表面。

可切换实验模式：`IDWriteGlyphRunAnalysis::CreateAlphaTexture(DWRITE_TEXTURE_CLEARTYPE_3x1)` 提取真实三通道覆盖率，按显示器 RGB/BGR 排列处理，再根据参考背景编码为普通预乘 BGRA。可选择 50%、75%、100% 子像素强度。

统一 alpha 为覆盖率最大值，颜色为 `coverage[k]*text[k] + (alpha-coverage[k])*referenceBackground[k]`。输出满足预乘约束。数学测试验证参考背景一致时的 source-over 等价性。

实验使用参考浅色背景，不采样桌面。因此实际背景偏离参考色会产生误差；尚未模拟原生 ClearType 全套 gamma/contrast 校准。背景快速变化、HDR、旋转屏幕及混合 DPI 仍待进一步视觉验收，不能宣称与原生不透明 ClearType 完全等价。有色边时可降低强度或切回灰度。系统会自行决定透明效果关闭等情况下的材质回退。

## 构建

需要 Visual Studio C++ 桌面工作负载、Windows SDK 和 CMake（仅构建机需要）。本机使用 VS 2026、SDK 10.0.26100，Release `/MT`。

```powershell
cmake -S . -B build -G "Visual Studio 18 2026" -A x64
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

`ZCodePet.exe --probe` 只读检查观察器、浮层布局、实际渲染后端及帧时钟，并写 EXE 旁边的 `probe.txt`，不输出会话标题或内容。可查看 displayHz、vblankClock、visualFrameAverageMs、panelCenterOffset 和各 renderer 字段。`--self-test` 验证回合顺序和覆盖率数学；`--panel` 启动时展开面板。`--quit` 正常退出已运行的桌宠。

`--demo --preview --panel` 为窗口验收模式：仅生成本地演示会话，覆盖工作中、等待、完成、错误、中断及未知六种状态，可滚动检查，8 秒后触发完成，12 秒后追加一个回答请求，20 秒后模拟回答解除，可检查提醒保留及手动排队关闭，不读写 ZCode 状态；预览面板持续显示，方便截图。正式运行不要加这两个参数。

`--preview --panel --navigation-preview` 读取当前真实会话，额外显示一条明确标记为“导航预览”的本地提醒，便于验证正文点击；不伪造 ZCode 状态或发送消息。演示模式禁用会话导航。`--navigation-test` 验证导航身份、标题更新、歧义、行命中及透明像素命中规则，已加入 CTest。`--probe` 额外输出不含会话身份的导航状态/匹配数量/动作枚举（code 2 表示 UIA 动作成功返回，action 1 为 Invoke），不等同于对 ZCode 页面加载完成的确认。

`--interaction-motion-test` 检查交互曲线、中途反向、短按保留、移出取消、单调性和归位末帧，已加入 CTest。`--probe` 的 `interactionFrames` / `visualFramesNeeded` 可检查反馈结束后是否停止高频帧；本机三个浮层均为 hardware，120 Hz 垂直同步下约 8.32 ms，静态悬停时两个帧需求均归零。

本机测得 DPI 168（175%），默认宠物从约 315 px 调整为 224 px，面板从约 504 px 加宽到 627 px，同时放大文字。

本机已检查 GIF 透明、紧凑单行亚克力面板、切回 ZCode 后仍保留材质、状态持续时间用 s/m/h/d 短格式递增、独立完成提醒、得意动画及字体切换。悬停离开、固定/取消固定、拖动时保持并跟随、跨间隙容错、去重、状态持续时间、短回合完成与动画状态选择有自动化逻辑测试；新增屏幕边界定位和浮层避让回归测试，覆盖负坐标显示器。已检查横向图标工具栏、大小子页、调节/恢复按钮和 Esc 收起，并检查固定偏好写入。几何测试检查字形存在且在胶囊范围内，以及字形 ink bounds 的横纵中心。尚未在独立的最低补丁版本虚拟机上验收，也未通过实际发送任务来制造权限或完成事件。已用用户当前真实的 AskUserQuestion 验证等待状态和提醒，程序不会代用户回答。已用当前官方版本的既有完成回合验证最终回复摘录可读，并用隔离的内存数据库测试回合匹配、思考/合成内容过滤及缺失时回退。
