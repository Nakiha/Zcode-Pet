# 性能测量

以下为 2026-10-29 本机 RTX 5080 / 120 Hz、默认约 224 px 角色的测量结果，描述应用进程 GPU 3D 引擎计数与 CPU/显存；不代表整卡功耗，也不能将整个 DWM 进程归给桌宠。

## 保留式 UI

三行工作会话、同材质对照：旧持续整窗重绘路径应用 3D 约 2.680%，最终 Windows Composition 路径两轮约 0.046% / 0.041%，面板基底从约 120 次/秒绘制降至约 1 次/秒（年龄更新）。此轮角色仍为旧帧动画，专用显存约 18.9 MiB；UI 的旋转与扫光没有取消或降刷新率。

系统合成器承担循环动画。DWM 在不同样本约 3.19%–4.39%，这是整个桌面的计数，不能据此推算桌宠的总 GPU 成本。切换 Mica 没有获得可归因的固定降幅，因此材质作为视觉选择保留。

## Spine 角色

采用默认小画布软件栅格路径后：仅角色时应用 3D 接近 0%，CPU 约 0.40%；含三行工作会话时，两轮应用 3D 约 0.082% / 0.067%，CPU 约 0.44% / 0.38%，专用显存约 18.92 MiB。可选原生 GPU 角色路径在该尺寸下约 0.9%–1.5%，故未作为默认。

这轮桌面流媒体采集已停止，DWM 计数没有可用于归因的数据，不能将零读数解释为全桌面 GPU 零成本。不同轮次的 GPU 时钟、桌面活动及采集状态会影响数据；这些数字不是通用保证。0.2.2 进行旧路径清理，没有重新声称获得额外 GPU 降幅。

角色普通 30 FPS，动作混合及短暂回弹期间 60 FPS；静态面板不因角色帧刷新。工作行共用两条合成器循环时钟，隐藏或移除后解绑，无工作行时停止。九个动作的 512 px 软件/硬件 PNG 参考对比，预乘通道平均差异低于 0.1/255，单像素通道差异均不超过 8/255。

## 复测

`scripts/profile-gpu.ps1` 使用本地固定场景，输出 `summary.json/csv` 和 `engine-samples.csv`，不写 ZCode、不记录会话内容、不保存诊断材质偏好，结束后恢复普通运行实例。采样时应记录显示器刷新率、GPU 时钟、流媒体采集和桌面活动。

可对照 `running` / `running-legacy`、`running-spine-gpu`、`running-no-shimmer`、`running-no-spinner`、`running-mica`、`running-solid`、`running-frozen`。`pet-frozen` 用于静态角色基线。应用计数与整卡/整个桌面的计数应分别解释。
